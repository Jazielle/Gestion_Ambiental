# Demostración de revisión de estaciones

## Objetivo de la práctica

Preparar un pull request documental para practicar la revisión entre compañeros. Esta entrega añade únicamente esta guía; no modifica el registro de estaciones ni corrige una funcionalidad.

## Escenario propuesto

Revisar que el listado muestre nombre, latitud, longitud y acceso a edición, y que el formulario permita comprobar los datos antes de guardarlos.

3. Registrar observaciones sobre la guía si corresponde.
