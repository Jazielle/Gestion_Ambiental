# Web de GeoCruz

Aplicación Laravel 12 y Blade desarrollada por Josué Padilla.

Consulta el README.md de la raíz del proyecto para instalación, ejecución y configuración de NASA y Google. Usa docs/MAPA_DEL_CODIGO.md para localizar el módulo Incendios.

El código propio está en app/Modulos/Incendios/, resources/views/incendios/ y public/modulos/incendios/. La demo funciona sin una base de datos ni una compilación de Node.
